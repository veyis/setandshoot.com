# Studio Phase 3 Implementation Plan — Seiten, Stammdaten, Rechtliches, Einstellungen

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the Studio (spec Phase 3): marketing page editing (`/studio/seiten`), taxonomy CRUD (`/studio/stammdaten`), legal pages (`/studio/rechtliches`), and settings (`/studio/einstellungen`). After this phase the beginner editor never needs `/admin` except for safety-locked rich text.

**Architecture:** Identical Studio pattern; REUSE without modification: `RichTextLocaleField` concept from `block-editor.tsx` (extract or replicate), `PhotoPickerSingle`, `RichTextMini`, `isSupportedRichText`, `altFor`/`richTextFor`, `requireAdminSession`/`StoryActionResult` in actions, the `toPayloadLayout` per-locale write contract.

**Write contracts (extend the Phase 2b experiment findings to globals):**

1. `payload.updateGlobal({ slug, data, locale, overrideAccess: true })` — DE write owns the `sections` block structure + DE values; conditional EN write attaches EN values by block `id` (re-read ids after the DE write, exactly like `updateStudioStoryContent`).
2. **Required localized fields must be present on EN writes** — self-heal with `en || de`: `pageHeader.title`, `ctaLink.label` (block subfields), `datenschutz.title` (global field). Required NON-localized fields (impressum legalName etc.) do NOT need resending (proven on stories: slug was never resent).
3. `serviceOffers.items` is a **localized array**: DE and EN have independent arrays (no cross-locale id matching). DE write sends `items: itemsDe`; EN write sends `items: itemsEn` only when `itemsEn` is non-empty, else omits.
4. Globals are LIVE singletons — no destructive experiments. Verification is a **no-op write probe**: read `aboutPage` locale-all, write the same values back through the new update function (DE+EN), re-read, assert deep-equal sections. Marketing-page afterChange hooks revalidate paths; in the probe strip hooks like `scripts/experiments/block-locale.ts` does.

**Field reference (verified against `src/payload/globals/*` and `src/payload/blocks/marketing/*`):**

- `settings`: `defaultWatermark` (bool), `accentColor` (text, hex, default `#E63946`), `homeFeaturedCount` (number 1–6)
- `impressum`: `legalName`\*, `addressLine1`\*, `addressLine2`, `postalCode`\*, `city`\*, `country`\*, `email`\* (email), `phone`, `ustIdNr`, `responsibleForContent`, `additionalNotes` (localized textarea)
- `datenschutz`: `title`\* (localized text), `intro`/`body` (localized richText), `lastUpdated`\* (date)
- Taxonomies: `teams` {`name`\*, `shortName`, `city`, `tier` (enum bundesliga|2-bundesliga|regional|youth), `published`}; `competitions` {`name`\*, `season`\*, `tier`, `published`}; `tags` {`name`\* localized, `slug`\* unique (reuse `SLUG_PATTERN`), `published`}
- Marketing blocks (`sections` on aboutPage/servicesPage/contactPage/athletesPage/highlightsPage):
  - `pageHeader`: `label` (loc), `title`\* (loc), `intro` (loc textarea)
  - `portraitFigure`: `photo` (optional photo id), `caption` (loc)
  - `editorialProse`: `eyebrow`, `title` (textarea), `body1` (richText), `pullQuote`, `body2` (richText), `credits` (textarea) — all loc, none required
  - `ctaLink`: `label`\* (loc), `target`\* (enum: `/contact` `/about` `/athletes` `/services` `/highlights` `/stories` `/`)
  - `serviceOffers`: `items` (LOCALIZED array of {`title`\*, `body`\*})
